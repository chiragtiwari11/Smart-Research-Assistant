# Smart Research Assistant

An AI-powered Research Assistant built with **Spring Boot, Gemini API, and Chrome Extension**.

## Features

- AI-powered research assistance
- Google Gemini API integration
- Chrome Extension with Side Panel
- Spring Boot REST API backend
- Research query processing
- Simple and user-friendly interface

##  Tech Stack

- Java
- Spring Boot
- Spring Web / REST API
- Maven
- Google Gemini API
- HTML
- CSS
- JavaScript
- Chrome Extension APIs
